# XJ380 内测申请

XJ380 Singularity (Version 1.0.0) 的开发工作已经进入收尾阶段。为完善各位观众朋友们的实际测试和使用体验，以及 XJ380 的兼容性， XJ380 现公开招募志愿测试员，协助完善 XJ380，进行发布前的最后冲刺。

## 申请要求
有测试工具（虚拟机）即可。同时需要有一定基础知识与调试能力，可以配合开发组进行调试。

## 选拔标准（按优先级排序）
- 有操作系统开发/调试经验者优先。
- 有软件开发/调试者优先。
- 有实体机测试条件并有能力协助调试者优先。
- 有多台设备/工具者优先。
- 有设计经验者优先。

## 内测内容
协助开发组测试 XJ380 的兼容性，查找 XJ380 的 bug ，同时完善相关功能和体验。

## 注意事项
1. 内测版为开发组日常用于**开发调试**的版本，编译参数等与最终版有一定差距，**不代表最终作品**。
2. 没有保密要求。但严禁将测试版镜像向公众公开/大规模外传，以免引起误解，但可以跟身边少数朋友分享，并邀请一同参与测试。同时也可以在各个平台发布相关测试视频，但必须标注“**调试版本，不代表最终作品**”。
3. 为了避免管理混乱/消息刷屏，本次只筛选少数人参与测试，工作室只接收最终选拔出的测试员的相关汇报；如果测试员想让身边少数朋友一同测试，还请测试员代为汇报，给各位带来的不便敬请谅解。
4. 违反相关限制并对工作室造成损失，工作室有权永久禁止您参与工作室作品/产品测试等活动。

## 需要准备的软件
- QEMU (Linux 环境且启用 kvm)
- GDB (建议和 QEMU 同环境)
- VMware
- Codex CLI/Codex Desktop
- WSL2 (如果你是 Windows 用户)

## 我们提供的资源
- XJ380 调试版镜像（.img 和 .vmdk 格式）
- GPT 指定模型的 Token（以 API Key 形式下发，使用指定的 URL）

## 申请方式
给这个仓库发 issue ，选用“内测参与申请”模板并如实填写相关信息。请您如实填写相关条目和联系方式，如有需要请附上您的作品链接/图片/网站等方便我们核查。
